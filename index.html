01 / BEFORE YOU START

실습 환경 준비

설치와 가입을 마쳤다면 아래 방법으로 확인해 보세요.

⌘STEP 01

Git 설치

운영체제에 맞는 Git을 설치한 뒤 터미널에서 버전을 확인합니다.

git --version
공식 설치 페이지 ↗이 항목은 제출한 출력 형식을 확인합니다. 실제 설치 여부를 브라우저에서 직접 검증할 수는 없습니다.
◎STEP 02

GitHub 가입

계정을 만들고 이메일 인증을 완료하세요. 공개 프로필을 조회해 계정 존재 여부를 확인합니다.

github.com/signup
GitHub 가입하기 ↗이메일 인증과 계정 소유 여부는 공개 API만으로 확인할 수 없습니다.
02 / YOUR MISSIONS

실습 과제

각 목표를 순서대로 수행하세요. 지정한 저장소를 기준으로 채점합니다.

8개 평가 항목
개인 계정 소유의 공개 저장소를 입력하세요.
01

공개 저장소 만들기

본인 계정에 공개 저장소를 만들고 위에 URL을 입력하세요.

git init → git remote add origin → git push
15점
02

README 작성하기

README.md에 학습 목표를 적고, git-lab-사용자이름 문구를 넣으세요.

git add README.md
15점
03

커밋 두 번 만들기

기본 브랜치에서 서로 다른 변경을 두 번 커밋하세요. 메시지는 자유롭게 작성할 수 있습니다.

git commit -m "docs: add learning goal"
15점
04

새 브랜치 푸시하기

practice/feature 브랜치를 만들고 GitHub에 푸시하세요.

git switch -c practice/feature
15점
05

이슈 열기

저장소에 학습 계획이라는 문구가 들어간 이슈를 만드세요.

GitHub → Issues → New issue
10점
06

Pull Request 만들기

practice/feature에서 기본 브랜치로 PR을 만드세요. 브랜치에 새 변경 사항을 커밋해야 PR을 만들 수 있습니다.

GitHub → Pull requests → New pull request
10점
✦

권장 순서: README와 커밋 2개를 기본 브랜치에 푸시 → 새 브랜치에서 파일 수정 및 커밋 → 푸시 → PR 생성. PR은 열려 있거나 병합된 상태 모두 인정합니다.
